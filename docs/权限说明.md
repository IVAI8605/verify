# 权限与隐私说明

> 适用于 v4.5.3 起的飞牛 fnOS 安装包。依据飞牛应用开放平台《应用权限》《应用资源》《Manifest》《应用入口》四篇官方文档：
> - https://developer.fnnas.com/docs/core-concepts/privilege/
> - https://developer.fnnas.com/docs/core-concepts/resource/
> - https://developer.fnnas.com/docs/core-concepts/manifest/
> - https://developer.fnnas.com/docs/core-concepts/app-entry/

## 一句话结论

应用以**专用 package 用户**运行，**不请求 root**，没有 Docker、共享目录或系统命令链接；文件读写只发生在用户在飞牛「系统设置 → 应用 → 查重助手」里显式授权的目录。唯一的附加用户组是 `render`，只用于可选的 Intel QSV 硬件解码，设备不可用时自动回退软解，不影响查重主流程。

## 包内声明

| 位置 | 声明 | 作用 / 为什么需要 |
|---|---|---|
| `config/privilege` | `run-as: package` | 以专用应用用户运行，与系统级权限隔离；这是官方推荐的默认方式 |
| `config/privilege` | `join-groups: ["render"]` | 允许打开 `/dev/dri/renderD128` 做 QSV 硬解抽帧；不加也能跑，但只能软解。只加 `render`，不加 `video`（`card0` 是显示输出，本应用不用） |
| `config/resource` | `{}` | 不创建共享目录、不向 `/usr/local` 暴露命令/库/配置、不使用 Docker 项目 |
| `manifest` | `disable_authorization_path=false` | 保留飞牛应用设置里的「授权目录」入口，让用户自己决定可访问范围；应用不能绕过该授权 |
| `app/ui/config` | `allUsers=false` + `control.accessPerm=readonly` | 入口仅管理员可见、设置项只读，避免普通账号误改服务地址与端口 |
| `manifest` | `service_port=${wizard_port}`、`checkport=true` | 只监听安装时选定的一个 HTTP 端口（默认 18898），不额外开端口 |

没有声明的能力：`run-as: root`、`video` 组、`data-share`、`usr-local-linker`、`docker-project`、系统服务/开机项。

## 超出「最小权限」的部分

严格按官方「能满足需求的最小权限」口径，本项目有两处需要额外说明：

1. **用户目录读写（业务本身要求）**
   查重必须读取文件内容、计算哈希，清理时必须能移入隔离区或删除。应用不申请整盘访问，只使用飞牛应用框架的目录授权；未授权目录在选择器里带锁，后端还会对每个请求路径做「Clean + 软链接解析 + 卷前缀重判」校验，拒绝 `..` 越界。授权可随时在飞牛「系统设置 → 应用 → 查重助手」里收回，收回后对应目录立即不可扫描。

2. **`render` 附加用户组（可选加速）**
   视频抽帧默认优先 `ffmpeg -hwaccel qsv`，需要访问 `/dev/dri/renderD128`。因此声明 `render` 组；这是本应用唯一超出 package 用户默认能力的系统组。若 NAS 没有 Intel 核显、设备节点不存在或初始化失败，`DetectHW` 会保持空模式，代码显式以 `-hwaccel none` 重试软解，功能不受影响。可只删 `join-groups` 重新打包来关闭硬件解码能力。

## 运行期还会接触什么

- **系统 FFmpeg**：调用 `/usr/bin/ffmpeg`、`/usr/bin/ffprobe`（可用 `VERIFY_FFMPEG` / `VERIFY_FFPROBE` 覆盖），只执行固定参数，不加载用户提供的可执行文件。
- **应用数据目录**：SQLite 索引、日志、隔离区与缓存都在 `@appdata/verify/data`（或 `-data` 指定目录）；卸载不删除。隔离区位于各扫描卷根的 `.verify-trash`，删除前先写审计记录。
- **网络**：只监听安装向导选定的 HTTP 端口，供局域网浏览器访问；不主动外联、不上传文件、不接第三方统计。访问令牌可选：未设置时同网段可直连，设置后在登录页校验；令牌比较走 SHA-256 + 常量时间比较，Cookie 不存明文。对外暴露到公网前请设置令牌并加 HTTPS 反向代理。

## 如何核对与收回

```bash
# 运行身份与附加组（安装后）
id verify
# 期望：uid=...(verify) gid=... groups=... render ...

# 渲染节点
ls -l /dev/dri/renderD128

# 硬件解码是否真的启用（需令牌）
curl -H "Authorization: Bearer <token>" http://<NAS>:18898/api/status
# 期望含 "hw_mode":"qsv"；为 "" 表示已回退软解
```

- 收回目录：飞牛「系统设置 → 应用 → 查重助手」删除授权目录；本应用设置页同步移除扫描路径。
- 关闭硬件解码：从 `packaging/fpk/config/privilege` 删除 `join-groups` 后重新打包。
- 限制访问：设置访问令牌，或只让管理员使用（默认入口已 `allUsers=false`）。

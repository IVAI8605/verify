# 查重助手（Verify）

飞牛 NAS 上的重复文件清理与实时查重工具。单个 Go 二进制，内置中文 Web UI，数据保存在本地 SQLite，支持飞牛 fpk 安装包。

## 功能

- **新建查重向导**：先选择查重依据组合，再选择扫描文件夹和排除文件夹，确认后保存全局配置并开始查重；结果只显示本次选中的目录。
- **本次扫描概况**：概览页显示本次枚举到的文件数、扫描范围总大小、当前阶段进度、已用时与跳过明细（排除文件夹/非普通文件/读取失败/小文件/校验失败），扫描中每秒刷新，结束后保留结果。
- **搜索规则组合（v3.9.0 起取代旧的匹配模式下拉）**：向导与设置页用规则编辑器选「主依据」（精确内容 / 忽略内容（属性）/ 按大小 / 按文件名 / 视频 / 片头 / 音频 / 图片 / 文件夹 / 模糊名 / 语义 / 全部），再叠加任意附加条件（相同文件名、相似文件名、相同大小及容差、相同扩展名、相同驱动器、相同修改日期、相同文件夹名称、忽略「副本」、忽略同文件夹、区分大小写）；条件之间是 AND。「忽略内容 + 相同大小」就是纯按大小分组，不读取文件内容。规则可存成命名预设供下次套用；清理计划可复用其中的**非媒体规则**（精确内容 / 忽略内容 / 按大小 / 按文件名 / 模糊名 / 语义等），视频 / 片头 / 音频 / 图片 / 文件夹类规则暂不参与清理计划，仍按旧 `match_mode` 分组；旧 `match_mode` / `match_kinds` 仅作兼容字段保留。
- **单一结果页 + 全量内存快照（v3.9.0）**：精确重复、相同视频、同名、相似视频、片头、音频、图片、文件夹、模糊名、语义等类型合并进一个「结果」页，用类型 chips 筛选，旧标签深链自动映射。搜索阶段把全部命中装进内存一次建组，首屏与滚动不再查库，也不再有 3000 组截断；内存超上限时明确报错并给建议，不静默截断。
- **扫描可视化**：概览页文件类型分布环形图（自绘 SVG、零依赖，最多 8 类 + 其他，带图例与悬浮提示），枚举时每 500 个文件刷新、前端 1 秒节流；存储卷悬停显示该目录下已索引文件数与总大小。
- **结果页交互**：重复组可折叠、可一键全部折叠/展开；每列宽度可拖动调整并按结果类型记忆，双击列边缘恢复默认。
- **完整失败信息**：视频分析失败原因自动换行完整显示，并支持一键复制；页面随窗口最大化自动铺满。
- **精确查重**：先按文件大小与头尾各 4KB 预哈希筛掉不同文件，再对候选计算 BLAKE3 完整哈希，识别字节级完全相同的文件。
- **快速查重**：只跑预哈希与 BLAKE3，跳过视频/片头分析，适合“只找完全相同文件”的秒级场景；顶部实时显示已用时间与完成/总数。
- **同名分组**：按文件名归组，快速清理同名副本。
- **相似视频**：提取正片区间的 5 秒音频频谱指纹 + 分散帧 dHash（帧密度三档可选：低 3 帧/中 6 帧/高 10 帧）；可配置忽略片头/片尾秒数，阈值附近再做轻量正片帧校验。
- **相同片头**：独立分析视频开头 1–300 秒（默认 10 秒），只保留“片头相同、正片不同”的视频，并自动剔除整段重复文件。
- **大文件 Top N**：按大小排序的已索引文件列表（从大到小/从小到大），勾选直接移入隔离区；只覆盖已索引文件。
- **空目录检测**：后序遍历空目录树，整目录移入隔离区（深度降序、执行前重验非空），可恢复；隔离区/排除/保护目录不参与。
- **损坏文件检测**：视频/音频走 ffmpeg 解前 1 秒；图片（防解压炸弹）、zip 系、JSON、XML 纯 Go 校验；超限文件记「过大未检」；只报告不推荐删除。
- **临时文件清理**：健康页独立一类检测——命中可编辑清单（.tmp/.bak/.crdownload/.part/Thumbs.db/desktop.ini 等，浏览器副本类默认不含）即报告数量/体积；勾选清理进隔离区可恢复；保护文件夹双拦。
- **模糊文件名分组**：文件主名统一转无调拼音音序键后分组——"沙丘" 与 "shaqiu" 归同组；支持近似匹配（音序键单字差异，编辑距离 ≤1）；纯数字/符号名不参与；仅分组展示不参与删除判定。
- **文件名解析基建**（internal/fname）：规范化/音序键/编辑距离分组共享实现，供拼音模糊名、语义分组与文件夹重命名复用。
- **语义分组**：文件名剥掉分辨率/编码/片源/语言字幕等噪声（词典+规则，设置页可编辑）后按核心键分组——"沙丘.2016.1080p.HEVC" 与 "shaqiu 2016" 归同组；仅辅助展示，不参与删除判定。
- **按文件夹改名**：概览页工具——相机码/纯序号文件（IMG_1234、001.png 等）批量替换为 `<文件夹名>_001`，有描述的文件默认保留原名（可选加 `文件夹名 - ` 前缀）；预览逐行可查、撞名自动加序号、执行后可撤销；保护目录拦截。
- **竖横屏识别**：ffmpeg cropdetect 片头/片中/片尾三点采样取众数，按有效画面长宽比归类横屏/竖屏/方形；大文件页一键批量识别、按比例筛选。默认仅打标签零转码成本。
- **智能保留策略**：选择助手一键打分建议每组保留哪个——信号集（分辨率/码率/编码完整性/路径整洁/文件名质量/修改时间，损坏一票否决）+ 置信分级（高/中/需人工）；应用建议只改选择标记、永不自动删除；偏好学习记录采纳/改选（设置页可重置）。
- **文件健康**：空文件、空目录、扩展名与内容不符（magic bytes）、损坏文件（视频/音频/图片/zip/JSON/XML）、文件名不规范（emoji/多余空格/重复标点）、繁体文件名、临时文件共 7 类检测，支持批量修正扩展名、繁简改名、移入隔离区；**改名类操作**（修正扩展名/繁简改名）可按任务撤销；**移入隔离区的清理**请到隔离区页恢复（已做逐条路径复核）；闲时自动巡检（默认关）。
- **保护文件夹**：扫但禁删——文件照常进查重与展示，隔离/删除一律拦截，五个清理入口预检+执行双拦。
- **移动文件**：结果页勾选 →「移动到…」选目录（第一版仅同卷）；冲突自动追加 `_1` 绝不覆盖；审计可一键撤销回原位。
- **结果页改名**：单文件改名与组内统一命名，复用改名基建，冲突自动追加序号、操作可撤销。
- **片头剪除**：视频开头 N 秒整段剪除（临时文件预览确认后再落位），支持替换原文件或另存新文件。
- **硬链接合并**：精确重复组内一键把勾选文件变成指向保留者的硬链接——文件都还在、实际只占一份空间；预检同卷/保护/内容一致性，临时链接 + 原子替换保证任何时刻目标有效。
- **重复音频**：纯音频文件（mp3/flac/m4a/aac/ogg/wav/wma/ape）按设置比较前 15 秒（默认）/前 2 分钟/全片，提取频谱指纹聚类；2 分钟与全片档自动收紧相似度门槛。ffmpeg 不可用或音频过短（<0.5 秒）自动跳过并进入失败列表。
- **重复文件夹**：目录内全部已哈希文件的「名字+大小+哈希」签名（单层目录，不含子目录内容），整体复制的文件夹归为一组；组内按目录二级展示（「建议保留」/「重复」徽标），重复目录默认预勾选，打开页面即可一键隔离。可在向导第 3 步或设置页关闭「计算重复文件夹」——关掉只影响该页打开速度，不影响扫描。
- **相似图片**：4 方向 dHash 感知指纹（旋转 90°/180°/270°、水平翻转、缩放、重压缩均判相似），网格缩略图展示。支持 jpg/png/gif/bmp/tiff/webp（按文件内容识别）；**HEIC/AVIF/JXL/RAW/SVG 不支持**——HEIC 是 iPhone 默认格式，同步到 NAS 前需先转换。
- **短视频与失败重试**：小于 3 秒的视频自动降级为单帧指纹；无法解码的文件进入失败列表，可单个或批量重试。
- **实时监控**：通过 fsnotify 监听目录变化，新增或修改文件自动补算。
- **隔离区**：删除默认移入各卷的 `.verify-trash`，可恢复或永久删除。
- **CSV 导出**：兼容 Duplicate Cleaner 格式，并补充媒体字段；导出内容以当前标记为准。
- **HTML 报告**：生成自包含缩略图、分辨率、编码、时长与标记状态的结果报告。
- **选择助手**：左侧面板提供作用范围、全标记警告、撤销栈、组级保留、偏好排序（分辨率/大小/时长/修改时间/创建时间/码率/采样率/路径深度/文件名长度）、优先路径和文本标记，文本支持正则与整列匹配。
- **批量预检**：移入隔离区、恢复、永久删除前先展示逐项校验结果和失败原因。
- **目录选择**：日志、缓存与扫描目录支持内置浏览弹窗，逐级进入、新建文件夹；扫描目录可多选，也保留手动输入。
- **行选择**：结果行支持 Windows 习惯的单击单选、Ctrl 多选、Shift 连选；选择助手可一键填入选中行路径。
- **流畅结果页**：分块加载 + 虚拟滚动，只渲染可视分组；扫描收尾预取第一块，扫描完成后直接显示，再静默刷新保证一致。
- **中文日志**：按 24 小时制记录中文信息/警告/错误，单文件 10MB 自动轮转保留 5 个，日志目录可在设置中更改。
- **缓存目录可改**：缩略图缓存目录可在设置中切换，避免系统盘被占满。
- **核显加速**：优先调用飞牛系统 FFmpeg，探测 Intel QSV/VAAPI 硬件编码；失败时自动回退软解。
- **视频转码**：结果页勾选批量转码 H.265 MP4（平衡/高质/极速三档、可选限制 1080p），核显优先（hevc_qsv → hevc_vaapi → libx265 逐级探测）；聚合进度、可暂停全部任务 / 可取消单个转码，转码产物顶替原位、原文件进隔离区可恢复。
- **筛选与穿梭框向导**：结果页顶部单一筛选入口聚合大小/扩展名/时间/关键字等六维条件；新建查重向导用穿梭框双列选择扫描/排除/保护目录。
- **操作手册**：内置中文帮助中心（12 个章节，按模块折叠，页面里的 ? 可深链直达），零外部资源。
- **缓存管理**：设置页按类显示指纹/探测/缩略图（内存+磁盘）占用与单项清理；缓存目录落机械盘时提示迁移到 SSD；内存缓存预算自动检测（按系统内存）可手动覆盖；缩略图磁盘上限可配；损坏缓存项自动剔除重建。
- **每日定时唤醒（数据保鲜）**：默认关闭、授权时段（默认 04:00–08:00）内唤醒硬盘做增量对账与健康巡检——首次全盘扫描后靠实时监控+定时保鲜保持数据常新，打开软件即可直接勾选；时段结束自动停止让硬盘休眠。
- **闲时任务让路**：闲时巡检期间检测到磁盘持续读写会自动暂停、恢复空闲自动续跑；手动暂停优先级始终最高。

### 上面未单列的能力（v2.x–v3.x 陆续加入）

- **文件搜索**：内存文件名索引，支持子串、通配符 `* ?`、正则、区分大小写，以及扩展名 / 大小 / 时间 / 目录过滤与排序；索引只驻内存，重启自动重建，未就绪时回退数据库查询，不阻塞扫描。
- **规则搜索**：把当前规则的全量命中做成内存快照，可按类型与关键字分页查看、导出、取消；快照未就绪时返回明确的 409 提示。
- **独立「重命名」页**：搜索结果批量加入清单，11 种改名方法可串成方法链（替换 / 编号 / 大小写 / 时间戳等），支持 `<Inc Nr:N>`、`<Year>`、`<Width>` 等标签，预览后按批撤销；方法链可存为预设。
- **清理计划**：按 daily / weekly / interval 定时执行，可设最小体积、组内最少文件数、扩展名、保留策略与单次上限；执行只把文件移入隔离区，不永久删除。
- **元数据标签**：自定义标签项，取值可来自目录名或文件名正则，四种匹配模式，可参与辅助分组、结果页过滤与行内徽标展示。
- **跨设备指纹包**：导出 `path/size/hash/quick` 给另一台设备导入，按机器名管理，用于标记「另一设备也有的文件」；不传文件、不传凭据。
- **操作记录（审计）**：`op_log` 表记录登录、鉴权失败、设置变更、写请求与删除类操作，可按条件查询、导出 CSV、按保留期清理；永久删除与清空隔离区先独立记账，写不进去就拒绝删除。令牌等敏感字段只记「已修改」。
- **访问令牌**：首次启动自动生成（配置 0600，另写 `access-token.txt` 便于登录前查看），支持查看 / 更换 / 清除，登录失败按来源 IP 限速锁定。
- **隔离区导出备份**：把选中或全部隔离条目打成 zip 留底，成功导出的条目显示「已备份」徽标。
- **智能保留偏好学习**：记录采纳与改选，满 20 条后平滑调整权重，可查看档案、启停反哺、一键重置；可选本地 AI 端点只生成解释文字，不参与保留判定。
- **授权目录自动发现与诊断**：`/api/diag/authz` 可核对「飞牛授权 ↔ 应用可见」的对应关系；目录选择器支持粘贴已授权路径直达。

## 界面

Web UI 默认监听 `:8898`，共 12 个页面：概览、结果、大文件、文件搜索、重命名、视频转码、文件健康、隔离区、导入、操作手册、操作记录、设置。

旧版里「精确重复 / 同名文件 / 相似视频 / 相同片头 / 相似图片 / 重复音频 / 重复文件夹」是独立标签页，v3.9.0 起合并为「结果」页并用类型 chips 切换。设置页主表单内含访问令牌；另有元数据标签、清理计划、跨设备指纹包、缓存管理 4 个独立面板。

## 构建

前置条件：

- **Go 1.26+**（`go.mod` 声明 `go 1.26.0`），需支持 `CGO_ENABLED=0` 交叉编译
- **bash + GNU coreutils**（`scripts/` 下均为 `.sh`；Windows 上用 Git Bash 或 WSL）
- **fnpack 1.2.3+**（仅打包 fpk 需要），从飞牛官方开发者文档获取并加入 `PATH`：<https://developer.fnnas.com/docs/cli/fnpack/>
- 可选：`node`（`scripts/quick-check.sh` 用它做前端语法检查）、`pwsh`（仅维护者本地脚本使用）

```bash
# 本地调试
go build -o verify .

# 静态构建 Linux amd64
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -buildvcs=false -trimpath -ldflags "-s -w" -o packaging/fpk/app/bin/verify .

# 打包 fpk（产物输出到 dist/，根目录保持整洁）
bash scripts/build-fpk.sh
```

## 运行

```bash
./verify -data /path/to/data -addr :8898
```

首次运行会生成 `config.json`，可在 Web UI 设置页修改扫描目录、排除目录、最小文件大小、视频分析并发数、音频/缩略图阈值等。

视频分析依赖系统 `ffmpeg` / `ffprobe`，默认查找 `/usr/bin/ffmpeg`。可通过环境变量覆盖（新前缀 `VERIFY_`，旧前缀 `DUP_CLEAN_` 继续兼容）：

```bash
VERIFY_FFMPEG=/usr/bin/ffmpeg
VERIFY_FFPROBE=/usr/bin/ffprobe
```

### 飞牛核显说明

fpk 不打包静态 FFmpeg，而是复用系统 FFmpeg。部分 Intel 设备需要启用内核 GuC/HuC：

```bash
# /etc/default/grub 中加入：
GRUB_CMDLINE_LINUX_DEFAULT="... i915.enable_guc=3"
sudo update-grub
# 重启后验证
dmesg | grep -i guc
ffmpeg -hide_banner -encoders | grep qsv
```

若硬解失败，程序会自动回退到软解并记录失败原因。

## 硬链接合并怎么用（v1.13.0）

**前置条件**：要保住的文件所在目录已加入设置页的「保护文件夹」；确认文件系统支持硬链接（ext4/btrfs 原生目录均支持）。
1. 跑一次完整扫描，进「结果」页、类型选「精确内容」（硬链接只对**字节完全相同**的文件有意义）
2. 用选择助手「每组保留一个」+ 偏好选「修改最新」，让最新那份当保留者
3. 确认组里剩下的文件确实不需要独立副本（硬链接后共享同一份数据，改一个全变）
4. 点「硬链接合并（勾选为目标）」——弹出预检结果，逐项核对后确认；**红字提示此操作无法撤销**
5. 逐项显示结果：成功的标「已链接」，失败的显示原因（跨卷 / 受保护 / 内容已变化）
6. 结果页该组会标「已链接，不占额外空间」，可回收空间归 0，下次不再提示合并

**合并之后**：所有路径都还在、都能正常打开、被 SMB 访问；实际只占一份空间；`ls -li` 可见 inode 相同。**如需恢复独立副本**：在文件管理器里对某个路径复制一份替换掉（代价是重新占用空间）。

**注意**：同卷的目录树内才能硬链接；跨卷、保护文件夹、隔离区内的文件一律拒绝；执行时用「先建临时链接、再原子替换」的顺序，任何时刻目标路径都有效。

各版本完整更新记录见 [CHANGELOG.md](CHANGELOG.md)。

### 前端类型层

`tsc --noEmit` 只做类型检查，**不产出任何运行时代码**：产物仍是 `internal/web/ui/*.js` 原生脚本，
由 `go:embed` 内嵌，无 CDN、无运行时依赖。

- `webtypes/types.d.ts` —— **自动生成**，源头是 `internal/web/contracts*.go` 里 struct 的 json tag。
  改后端响应字段后运行 `python3 tools/gen_types.py` 重新生成，不要手改。
- `webtypes/frontend.d.ts` —— 前端自己需要的类型（如表格列定义），手写。

```bash
npm install            # 装 typescript（唯一的 devDependency）
python3 tools/gen_types.py      # 重新生成前端类型
bash scripts/quick-check.sh     # 门禁里会校验类型与后端契约是否同步
```
